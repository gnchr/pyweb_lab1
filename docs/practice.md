# Практикум: каталог учебных тем

Объедините разметку, стили, JavaScript и Python в небольшой каталог. Цель — пройти весь путь от запроса браузера до изменения интерфейса.

## Задание

1. Создайте структуру проекта из раздела [Python](python.md).
2. Добавьте заголовок, описание и адаптивную сетку карточек по примеру [HTML/CSS](frontend.md).
3. Запустите API со списком тем.
4. Загрузите список через `fetch` и создайте для каждой темы карточку с помощью `document.createElement` и `textContent`.
5. Добавьте поле фильтра. На событии `input` показывайте темы, содержащие введённую строку без учёта регистра.
6. Показывайте отдельные состояния: «Загрузка», «Ничего не найдено» и «Ошибка загрузки».

!!! tip "Начните с работающего минимума"
    Сначала выведите темы в один абзац. Затем добавляйте карточки и фильтр. Так проще понять, на каком шаге появилась ошибка.

## Чек-лист результата

- [ ] Страница открывается через локальный сервер и возвращает HTTP 200.
- [ ] API возвращает JSON и заголовок `Content-Type: application/json; charset=utf-8`.
- [ ] Неизвестный API-маршрут возвращает 404.
- [ ] Темы появляются на странице после запроса.
- [ ] Фильтр работает для пустой строки, разного регистра и отсутствующей темы.
- [ ] Поле фильтра имеет связанную подпись `label`.
- [ ] Интерфейс доступен с клавиатуры и помещается на экране шириной 360 пикселей.
- [ ] Ошибка сети отображается понятным сообщением.

## Что записать в отчёт

Опишите структуру проекта, приведите снимки интерфейса и Network. Для каждой реальной ошибки запишите симптом, причину, исправление и повторную проверку. Не добавляйте выдуманные ошибки ради объёма.

| Симптом | Возможная причина | Как проверить |
| --- | --- | --- |
| CSS не применяется | Ошибка в относительном пути | URL файла и статус в Network |
| Вместо тем — ошибка | Сервер остановлен или маршрут отсутствует | Статус запроса и журнал сервера |
| Скрипт не находит элемент | Неверный селектор или ранний запуск | `id` элемента и атрибут `defer` |
| На телефоне появляется прокрутка | Фиксированная ширина элемента | Размеры элементов в инспекторе |
