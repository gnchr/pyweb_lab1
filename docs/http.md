# HTTP: запрос и ответ

Браузер отправляет запрос, сервер возвращает ответ. HTML, CSS, JavaScript и JSON передаются отдельными HTTP-ответами.

## Один обмен данными

Пример запроса к учебному API:

```http
GET /api/topics HTTP/1.1
Host: localhost:8001
Accept: application/json
```

Ответ:

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"topics": ["HTML", "CSS", "JavaScript", "Python"]}
```

Метод сообщает намерение клиента, путь выбирает ресурс, заголовки передают метаданные. Тело ответа содержит представление ресурса.

## Методы и статусы

| Метод | Типичное назначение |
| --- | --- |
| GET | Получить представление ресурса |
| POST | Передать данные для обработки, например создать запись |
| PUT | Создать или заменить состояние ресурса по указанному адресу |
| DELETE | Удалить ресурс |

| Статус | Значение | Что проверить |
| --- | --- | --- |
| 200 | Запрос выполнен | Содержимое ответа |
| 201 | Ресурс создан | Адрес созданного ресурса |
| 400 | Некорректный запрос | Формат и параметры |
| 404 | Ресурс не найден | URL и маршрутизацию |
| 500 | Ошибка сервера | Журнал и обработку исключений |

!!! tip "Откройте Network"
    Перезагрузите страницу с открытой вкладкой Network в инструментах разработчика. Найдите документ, стили и скрипты; посмотрите статус, тип содержимого и длительность загрузки каждого ресурса.

## Простая модель времени ответа { #performance }

Для последовательного запроса без дополнительных обменов оценим общую длительность как сумму сетевой задержки, обработки и передачи данных:

<div class="formula">
<math display="block" aria-label="T равно RTT плюс t обработки плюс S делённое на B">
  <mrow><mi>T</mi><mo>=</mo><mi>RTT</mi><mo>+</mo><msub><mi>t</mi><mtext>обр</mtext></msub><mo>+</mo><mfrac><mi>S</mi><mi>B</mi></mfrac></mrow>
</math>
</div>

Здесь **RTT** — время сетевого обмена туда и обратно, **tобр** — время обработки на сервере, **S** — размер ответа в байтах, **B** — скорость передачи в байтах в секунду. Текстовая запись: `T = RTT + tобр + S / B`.

Если RTT = 40 мс, обработка занимает 10 мс, ответ весит 100 000 байт, а скорость равна 5 000 000 байт/с, оценка составляет 70 мс. Это учебная модель: она не учитывает установку соединения, TLS, кэш и параллельную загрузку ресурсов.

Формула представлена встроенным MathML, поэтому не зависит от внешних CDN. Текстовая запись остаётся доступна даже в браузере без поддержки MathML.
