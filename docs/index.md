## Как заниматься

1. Прочитайте раздел и запустите пример локально.
2. Измените одну деталь: стиль, обработчик события или ответ сервера.
3. Проверьте результат в инструментах разработчика браузера.
4. Соберите мини-проект из [практикума](practice.md) и пройдите его чек-лист.

!!! tip "Что потребуется"
    Текстовый редактор, современный браузер и Python 3.12 или новее. Для примера сервера дополнительные Python-пакеты не нужны.
